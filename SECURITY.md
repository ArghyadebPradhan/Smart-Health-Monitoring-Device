# Security Policy

## Reporting a vulnerability

Please do not publish Firebase credentials, personal health records, GPS tracks, or exploitable security details in a public issue. Report security concerns privately to the repository maintainer using a contact method listed in the GitHub repository profile.

## Security expectations
- No private keys, access tokens, passwords, or service-account files in source control.
- Firebase rules must restrict read/write access to authorized users and devices.
- Do not rely on client-side UI checks as the only authorization layer.
- Use synthetic data in issues and screenshots.
