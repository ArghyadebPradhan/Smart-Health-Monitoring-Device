# Contributing

Thank you for your interest in this educational prototype.

## Before opening a pull request
- Explain the change and the reason for it.
- Include board/module details for hardware changes.
- Test compilation and describe the test setup.
- Do not include credentials or personal health/location data.
- Update wiring, setup, and limitations documentation when behaviour changes.
- Keep medical claims conservative and evidence-based.

For bug reports, include the board variant, firmware commit, library versions, a minimal sanitized log, and reproducible steps.
